# 📜 Proof of Existence on Stellar (Soroban)

## 🔍 Project Description

This project implements a **Proof of Existence** system using the **Soroban smart contract platform on Stellar**. It allows users to securely store a cryptographic hash of a document on-chain, proving that the document existed at a specific point in time without revealing its contents.

---

## ⚙️ What it does

* Takes a **hash (SHA-256)** of any file or data
* Stores the hash on the blockchain with a **timestamp**
* Allows anyone to verify:

  * Whether the data existed
  * When it was recorded

---

## ✨ Features

* ✅ Tamper-proof record using blockchain
* ✅ Timestamp verification
* ✅ Duplicate proof protection
* ✅ Lightweight and efficient storage
* ✅ Privacy-preserving (only hash stored, not actual data)
